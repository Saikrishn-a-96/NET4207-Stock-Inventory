NET4207 Stock Inventory Manager

A Flutter application for managing stock items with live Firebase Firestore storage, validation, search, and low-stock filtering.

View on GitHub

Features

  • Scrollable form with full validation before writing to Firestore
  • SKU format STK- + three digits; item name at least 3 characters (trimmed)
  • Category limited to Electronics, Stationery, Hardware, or Grocery
  • Quantity and reorder level: non-negative whole numbers; price > RM 0
  • Form clears only after a successful Firestore write; errors shown inline
  • Live record list with loading, empty, and error states
  • Partial, case-insensitive search on item name or SKU
  • Combined filters: category, keyword, and low stock (quantity <= reorderLevel)
  • Quantity sorting in both directions; Clear filters restores the full list

Firestore schema

Collection: stockItems (Firestore-generated document IDs)

FieldType
skuString
itemNameString
categoryString
quantityInteger
unitPriceNumber
reorderLevelInteger
createdAtserver Timestamp

Getting started

  • Run flutter create . to generate platform files
  • Run flutter pub get
  • Connect Firebase with flutterfire configure (generates lib/firebase_options.dart)
  • Ensure Firestore is enabled and rules allow read/write on stockItems
  • Run flutter run (or flutter run -d chrome for web)
